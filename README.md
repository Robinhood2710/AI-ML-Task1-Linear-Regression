# House Price Prediction Using Linear Regression

## Objective

Build and evaluate a Linear Regression model using the California Housing Dataset.

## Dataset

California Housing Dataset from Scikit-Learn.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Joblib

## Model Evaluation

* MAE = 0.5332
* RMSE = 0.7456
* R² Score = 0.5758
