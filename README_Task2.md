# AI-ML Task 2: Feature Engineering & Model Comparison

## Objective

Compare multiple machine learning regression models on the California Housing Dataset using feature scaling and performance evaluation.

## Dataset

California Housing Dataset (scikit-learn)

## Models Used

1. Linear Regression
2. Ridge Regression
3. Decision Tree Regressor

## Techniques

* Feature Scaling using StandardScaler
* Train-Test Split
* Model Evaluation using RMSE and R² Score

## Results

The models were trained and compared based on RMSE and R² Score. The model with the highest R² Score was selected as the best-performing model.

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
